# JobSpy Fork — Roadmap (Plan-of-Plans)

**Created:** 2026-05-05
**Owner:** kbwhodat
**Upstream:** [Bunsly/JobSpy](https://github.com/Bunsly/JobSpy) @ `fda080a` (HEAD as of fork)

## Why this fork exists

Upstream `python-jobspy` has been effectively dormant for the network-jobs scrapers since mid-2025. As of 2026-05-05, **3 of 5 US-relevant scrapers are broken** in production:

| Scraper | Status | Failure mode |
|---|---|---|
| Indeed | ✅ Working | — |
| LinkedIn | ✅ Working | — |
| Google | ❌ Broken | `jsname="Yust4d"` regex no longer matches; Google moved Jobs to JS-only rendering with `enablejs` redirect |
| Glassdoor | ❌ Broken | `400 location not parsed` — fails to translate city strings to internal `locId` |
| ZipRecruiter | ❌ Broken | Cloudflare `403 forbidden aa` blocks all datacenter IPs |

Bumping the upstream version doesn't help — none of the recent commits address these. We fork, fix, and add ~14 new sources to broaden coverage for tech/networking job hunts.

## Phases

### Phase 0 — Foundation
**Plan:** [`2026-05-05-phase-0-foundation.md`](2026-05-05-phase-0-foundation.md)
- Dev environment, pytest + pytest-recording (VCR cassettes), ruff lint, `.env.example`, GH Actions CI, scraper authoring guide

### Phase 1 — Fix existing broken scrapers
- **1.1** Fix Glassdoor location-parser bug
- **1.2** Replace Google scraper with Playwright-based renderer (handles JS gate)
- **1.3** Wire ZipRecruiter through FlareSolverr (already in user's `~/Documents/projects/FlareSolverr/`)

### Phase 2 — New scrapers (14 plans, ranked by ROI)

**API-based (preferred — stable contracts, no scrape-warfare):**
- 2.1 **Adzuna** — large aggregator, free dev key
- 2.2 **USAJobs.gov** — federal cleared NOC roles, official free API
- 2.3 **Jooble** — large aggregator, free key
- 2.4 **Findwork** — free key
- 2.5 **The Muse** — open API, no key for read endpoints
- 2.6 **RemoteOK** — remote-only, free JSON
- 2.7 **Remotive** — remote-only, free JSON

**HTML scrapers (no free API exists):**
- 2.8 **Dice** — IT/tech focused, top ROI for network roles
- 2.9 **Snagajob** — built for shift/hourly work (NOC overnight)
- 2.10 **SimplyHired** — different index than Indeed despite shared owner
- 2.11 **Built In** — local tech (Atlanta, NYC, SF, etc.)
- 2.12 **Talent.com** (formerly Neuvoo) — large aggregator
- 2.13 **CareerBuilder** — declining but still indexes SMB
- 2.14 **Monster** — declining but distinct index

## Decision log

| Date | Decision | Rationale |
|---|---|---|
| 2026-05-05 | Fork rather than PR-only | Upstream dormancy + we want to ship now, can backport later |
| 2026-05-05 | Keep Poetry (not uv) | Match upstream tooling; uv migration = scope creep |
| 2026-05-05 | Prefer APIs over scraping where free | Stability + maintenance — APIs are 10x less brittle |
| 2026-05-05 | Use Playwright for Google (not Firecrawl) | User out of Firecrawl tokens; Playwright MCP already wired locally |
| 2026-05-05 | Use FlareSolverr for ZipRecruiter | Already installed locally; bypass datacenter-IP Cloudflare blocks |
